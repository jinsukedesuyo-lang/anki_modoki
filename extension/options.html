Ankiもどき キャプチャ

GitHub Pages で公開した URL（ローカル確認なら http://localhost:8080/）

使い方

  1. YouTube / Netflix で Language Reactor の字幕を表示
  2. 知らない単語をマウスで選択（ダブルクリックでも可）
  3. Alt+A（またはツールバーのアイコン / 右クリック →「Ankiもどきでカード作成」）
  4. 動画が一時停止し、字幕の文・単語の色付け・スクリーンショットが入った状態で追加画面が開きます
  5. 意味と語源画像を入れて保存

ショートカットは chrome://extensions/shortcuts で変更できます。Netflix は著作権保護によりスクリーンショットが黒くなる場合があります。
